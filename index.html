05

Case studies

CS-01 Broken Access Control — IDOR lab

objective

Prove that object-level authorization was missing on a multi-user application.

approach

Mapped endpoints referencing identifiers; two test accounts; replayed requests in Repeater swapping IDs; Autorize to detect missing ownership checks.

finding

GET /api/orders/{id} returned other users' data with a 200 — the server authenticated but never verified ownership.

impact

Full horizontal privilege escalation: any authenticated user could read any other user's orders and personal data.

remediation

Server-side ownership check on every object access, non-guessable identifiers, access-control regression tests in CI.

Performed in a controlled lab environment — no production systems touched.

CS-02 Authentication & Session Weaknesses lab

objective

Audit the complete session lifecycle: login, reset, storage and logout.

approach

Tested brute-force protection, analyzed reset-token entropy, inspected cookie flags, verified server-side invalidation after logout.

finding

Reset tokens were predictable; sessions not invalidated server-side after logout; cookies lacked Secure/HttpOnly on some paths.

impact

Realistic account-takeover paths: a leaked or reused token stayed valid indefinitely.

remediation

Cryptographically random tokens, server-side revocation, cookie hardening, rate limiting on sensitive flows.

Performed in a controlled lab environment — no production systems touched.
